# Introduction to Git 

### What is GIT ? 
Git is a free open-source software which helpful to manage versioning of our software basically it's save the snapshot of our code or codebase of our software to maintain multiple versions of it. If any error or code-break so we can roll-down to different version or roll-down to previous versions than we fix our software bug or analysis. 

Git also solve another problem store our software codebase on online repository if our machine goes down our codebase remain save on this cloud platforms like Github, Gitlab etc.
